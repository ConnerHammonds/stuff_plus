# CSV's Explained

## Original CSV's

"tm_ktx_merged.csv" is the original csv file containing Trackman pitch data as well as KinaTrax Biomechanical data

"tm_stuff_plus.csv" is the same data but cleaned up to remove all columns unneccessary to the calculation of stuff+ based on the current model

## Generated CSV's

CSV's generated from the "stuff_plus.ipynb" notebook file will be named using the following conventions

"stuff_plus_all_pitch-Date"
"stuff_plus_pitch_type-Date"
